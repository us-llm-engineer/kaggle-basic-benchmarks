# Provenance — Spooky Author Identification

- **Data:** `train.csv` (19,579 sentences, authors EAP / HPL / MWS), `test.csv` (8,392 sentences), `sample_submission.csv`; not redistributed. Fetch with
  `kaggle competitions download -c spooky-author-identification -p data && unzip data/*.zip -d data`.
- **Folds:** `results/folds.csv`, five stratified folds (`random_state=42`) created by `spooky_common.load()` and used by every model, so every out-of-fold number is on the same rows.
- **Selection protocol:** hyper-parameters, epochs and n-gram orders are chosen on an inner 10% hold-out of each fold's training rows, or on out-of-fold scores of the other folds; the outer fold is monitored but never selects anything.
  Probabilities are calibrated with a temperature (or, for language models, a score scale) fitted on the other folds' out-of-fold rows. Stack and pool parameters are fitted on the other folds only (nested).
- **Hardware and wall time of the heavy steps** (cloud sandboxes, one process per fold or configuration; timings from the start/finish stamps kept with each batch):

| Step | Hardware | Wall time |
| --- | --- | --- |
| word MKN LM, fastText-style classifier (29 units) | 16 CPU cores | 116 s |
| word Generalized Language Model grid (30 units) | 16 CPU cores | 180 s |
| char-TF-IDF MLP, first round (20 units, early stop) | 1 T4 GPU | 317 s |
| POS-tag networks (20 units, 4 encoders x 5 folds) | 1 L4 GPU | 384 s |
| MLP sweep, N = 4 (30 units) | 1 L4 GPU | 565 s |
| MLP sweep, N = 5 (30 units) | 1 L4 GPU | 1,272 s |
| cleaned-dataset study (7 members + stack on each of 3 datasets) | 16 CPU cores each, in parallel | 269 s, 263 s, 244 s |

  Everything else (assembly, pools, stacks, figures) ran locally in under 90 s per command.
- **Software of the cloud runs:** Python 3.12.10, numpy 2.5.3, scipy 1.18.1, scikit-learn 1.9.1, PyTorch 2.14.1 (CPU or CUDA 13 build), LightGBM 4.7.0.
- **Kaggle scores** (`results/kaggle_scores.csv`): stack of 8 members public 0.25663 / private 0.23384; 9-member pool + Dirichlet-style map 0.25784 / 0.23470; 7-member pool without the CNN 0.25700 / 0.23495.
- **What is not shipped:** the competition text (and the cleaned copies built from it), per-fold model checkpoints, large per-fold score archives, the feature caches. All are regenerated by the scripts listed in the README.
